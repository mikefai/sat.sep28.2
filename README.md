# Northstar SAT Reading & Writing Mock Exam

A complete, original two-module SAT-style Reading and Writing practice exam for the 2026 testing format. Northstar is an independent practice tool and is not affiliated with or endorsed by College Board.

## Run locally

```powershell
npm install
npm run dev
```

## Quality checks

```powershell
npm run validate:questions
npm run lint
npm run build
```

The exam contains 54 original questions: 27 in each 32-minute module. Progress is saved locally in the browser.
